# 抽屉组件设计规范

## 使用声明

本规范只定义抽屉的视觉、布局、交互和验收规则，不提供具体框架代码实现。

生成代码时，必须以当前项目的技术栈 Skill 为准。

如果本规范与项目技术栈约束发生冲突，优先遵守项目技术栈约束。

禁止在本规范中包含：
- React / Vue / Angular 代码示例
- JSX / TSX
- TypeScript 示例
- import 语句
- 具体组件库 API
- 具体组件库内部 class 的全局覆盖
- open / styles / footer 等特定版本 API 示例

本规范中的 Drawer、Footer、Button 等名称仅表示设计语义，不代表必须使用某个框架或组件库的同名 API。

## 核心规范

- 默认从右侧滑出
- 标题栏高度：48px
- 底部按钮栏高度：56px
- 默认宽度：800px
- 按钮区域：左对齐
- 按钮之间间距：8px
- 内容区域左右边距：32px
- 内容超出时，在内容区域内部滚动
- 抽屉宽度只能从以下尺寸中选择：
  - 640px
  - 720px
  - 800px
  - 960px
  - 1200px

## 结构

抽屉从上到下分为三层：

1. 标题栏
2. 内容区域
3. 底部按钮栏

## 标题栏

- 高度固定为 48px
- 标题文字垂直居中且左对齐
- 标题文字左边距 16px
- 标题文字字号 16px，字重 600
- 无底部分割线

## 内容区域

- 左右边距为 32px
- 上下无额外间距，内容区域紧贴标题栏底部和底部按钮栏顶部
- 上下不得增加额外的 padding 或 margin
- 内容超出时，内容区域内部滚动
- 表单、表格、详情内容都必须适配内容区域
- 内容滚动不能影响标题栏和底部按钮栏

## 底部按钮栏

- 高度固定为 56px
- 无顶部分割线
- 按钮左对齐，主按钮左间距 16px
- 按钮高度：32px
- 按钮文字：14px
- 主按钮位于最左侧
- 取消按钮位于主按钮右侧

## 验收标准

- 抽屉默认从右侧滑出
- 抽屉宽度符合允许尺寸列表
- 标题栏和底部按钮栏固定不滚动
- 内容区域独立滚动
- 底部按钮栏始终可见
